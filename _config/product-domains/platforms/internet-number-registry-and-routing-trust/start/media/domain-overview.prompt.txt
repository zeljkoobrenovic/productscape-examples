What the domain is: Internet Number Registry and Routing Trust covers the member, registry, routing security, DNS, policy, and measurement services needed to distribute and maintain Internet number resources and help operators keep Internet routing data trustworthy.
Customers: RIPE NCC Registry and Routing Trust Customers (4 customer roles)
Products: Member Registry Workspace (B2B); Registry Resource Lifecycle (B2B); Routing Trust Platform (B2B2C); DNS Authority and Root Operations (critical-infrastructure); Internet Measurement and Public Data Services (public-interest-platform)
Product bricks: 26 building blocks in groups: Registry Resource Management, Member Services and Governance, Routing Trust and DNS, Internet Measurement and Data
Data: People, Accounts, and Access Data, Commercial and Financial Data, Product, Catalog, and Content Data, Operational Workflow and Event Data, Risk, Governance, Security, and Compliance Data, Architecture, Portfolio, and Planning Data, Core Domain Records
Delivery channels: Member and Registry Control Plane: LIR Portal Production; Routing Trust and DNS Operations: RPKI and DNS Production; Public Data and API Surfaces: Measurement and Data Production
External systems: Identity Provider: RIPE NCC Access; Registry Coordination: Peer RIR transfer systems; Registry Context: IANA and peer RIR public data feeds; Enterprise Integration: Payment and finance systems; Community Integration: RIPE mailing lists and working group tooling; Vendor Integration: Exam delivery provider; Internet Standard: RPKI relying party software; Standards and Coordination: IETF and NRO RPKI coordination; Critical Infrastructure: Root server system and hosting partners; Community Infrastructure: Volunteer probe and anchor hosts; Internet Measurement: RIS route collector peers; External Consumer: Incident response and abuse reporting tools, Network automation, abuse desks, researchers, and public lookup tools, Member automation and registry update clients, BGP origin validation consumers
